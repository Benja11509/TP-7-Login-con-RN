# TP 7 - Login App React Native

## Prompt utilizado

Actúa como un desarrollador senior especializado en React Native y Expo. Necesito crear una aplicación móvil de Login para una entrega académica. La aplicación debe incluir un encabezado con el título 'Login App', campos para ingresar email y contraseña, un botón de inicio de sesión y una validación que compare los datos ingresados con credenciales definidas en el código. En caso de éxito debe mostrar un mensaje verde y en caso de error un mensaje rojo. Utilizá únicamente componentes nativos de React Native y el hook useState. Los estilos deben estar separados en un archivo llamado LoginStyles.ts utilizando StyleSheet.

## Cómo usé la IA

Durante el desarrollo del proyecto usé la IA como una herramienta de apoyo para resolver dudas y avanzar con partes del código que no sabía cómo hacer. Principalmente la utilicé para pensar la estructura del proyecto, organizar mejor las carpetas y entender cómo conectar las distintas partes, como el frontend, el backend y la base de datos. También le pedí ayuda para corregir errores que aparecían al ejecutar la aplicación.

Además, usé la IA para generar ejemplos de código y después adaptarlos a lo que necesitaba mi proyecto. Por ejemplo, cuando tenía problemas con el inicio de sesión, el registro o la navegación entre pantallas, le pregunté cómo podía resolverlo. No copié todo directamente, sino que fui probando, cambiando nombres, ajustando funciones y revisando que tuviera sentido con mi aplicación.

La IA también me sirvió para ordenar mis ideas. A veces sabía qué quería que hiciera la app, pero no sabía cómo explicarlo en código. Entonces usé ChatGPT para transformar esas ideas en pasos más claros, como separar las vistas, crear componentes y pensar qué funcionalidades eran realmente necesarias.

## Decisiones que tomé

Una decisión importante que tomé fue no usar todo lo que la IA me daba sin revisarlo. En algunos casos, la respuesta incluía funciones o estructuras que no coincidían con mi proyecto, entonces tuve que cambiar partes del código o directamente rechazar algunas soluciones. Por ejemplo, si la IA proponía una estructura demasiado compleja o con archivos que yo no estaba usando, decidí simplificarla para que se entendiera mejor.

También decidí adaptar el código a la forma en la que veníamos trabajando en clase. Aunque la IA podía dar soluciones más avanzadas, intenté mantener el proyecto ordenado y comprensible. Preferí que las vistas principales, como inicio de sesión, registro, home, perfil y escaneo, funcionaran bien antes que agregar muchas funcionalidades incompletas.

## Qué aprendí

Aprendí que la IA puede ser muy útil para programar, pero no reemplaza entender lo que uno está haciendo. Antes pensaba que podía dar una solución completa y lista, pero me di cuenta de que muchas veces hay que revisar, probar y corregir lo que genera. También aprendí a hacer mejores preguntas, explicando bien el error, el contexto del proyecto y qué resultado quería obtener.

Si tuviera que hacerlo de nuevo, usaría la IA de forma más ordenada desde el principio. Primero le explicaría bien la estructura del proyecto y después iría pidiendo ayuda por partes, en vez de mezclar muchos problemas juntos. En el código, intentaría planificar mejor las carpetas y componentes antes de empezar, para evitar errores y que el proyecto sea más fácil de mantener.
